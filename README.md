## 새 기능: 영수증 인식

영수증을 촬영하거나 갤러리에서 첨부하면 결제 금액, 사용처, 날짜를 자동으로 읽어 지출 등록을 도와줍니다. 사진과 OCR 원문은 기기 안에서 처리되며 서버에 저장되지 않습니다.

<img src="vflux-receipt-scan.png" alt="V-Flux 영수증 인식 기능 안내" width="420">

인식 결과는 영수증의 상태와 사진 선명도에 따라 달라질 수 있으므로 저장 전에 내용을 확인해 주세요.
